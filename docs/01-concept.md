# 01. コンセプト

## 課題

個人の学習習慣が続かない理由を、実際の運用（study リポジトリ 2026-09〜）から分解すると4つある。

### 1. 目標と今日の距離が遠すぎる
「TOEIC 600点」と「今日の30分」の間には何十段もの階段がある。
その階段を毎日自分で設計するのは、学習そのものより負荷が高い。
結果、「とりあえず単語アプリを開く」という**目標と無関係な学習**に流れる。

### 2. 間違いが「型」にならない
既存アプリは「Q7を間違えた」を記録する。しかし本当に必要なのは
「**冠詞を落とす癖がある**」「**be動詞と一般動詞を併用する癖がある**」という抽象化されたミスの型だ。
型にならない限り、別の問題で同じミスを繰り返す。

実運用では、英作文の添削1回から7つの型が抽出できた（冠詞落ち／be+一般動詞／副詞語順／
動詞後の品詞判断／hardly の誤用／複合名詞／スペル）。これは選択式ドリルの正誤だけでは絶対に出てこない。

### 3. 複数テーマを並行すると片方が死ぬ
語学と技術のように性質の違うテーマを同時に走らせると、
締切のある方に寄り、もう片方が「ゼロ日」を積んで消える。

### 4. 興味の変化が「失敗」として扱われる
トレンド性の高いテーマは鮮度が落ちる。既存アプリは中断＝挫折として記録するが、
実際には中断は正常な運用であり、再開しやすい形で保存されるべきもの。

## 提供価値

> **目標を渡すと、毎日「何を・どうやって・どこまで」まで決まった30分が届く。
> やった内容は自動で記録され、間違いはミスの型として蓄積され、忘れた頃に戻ってくる。**

## コアループ

```
  ┌─────────────────────────────────────────────────┐
  │                                                 │
  │   ① 提示  今日の30分メニューを自動生成           │
  │      ↓    （週次リズム × 各トピックの現在地）    │
  │   ② 実施  AI と対話しながらドリル／添削          │
  │      ↓                                          │
  │   ③ 記録  学習ログ・ストリーク・進捗%を更新       │
  │      ↓                                          │
  │   ④ 抽出  誤答と添削から「ミスの型」を抽出        │
  │      ↓                                          │
  │   ⑤ 反復  間隔反復キューへ投入 ────────────────┘
  │           （翌日以降のメニュー冒頭5分に混ざる）
  └─────────────────────────────────────────────────┘
```

このループが閉じていることが Ikkoma の全て。
④→⑤→① の還流があるので、続ければ続けるほどメニューが自分専用になっていく。

## ターゲット

| | |
|---|---|
| **一次** | 社会人の独学者。明確な目標（資格・技術習得）があり、まとまった時間は取れないが毎日30分なら出せる人 |
| **二次（Phase 2）** | 学習を見てもらいたい人 ↔ 見る人（メンター・上司・学習仲間） |
| **想定外** | 受験生向けの詰め込み、企業研修のコンプライアンス管理 |

## 差別化

| 既存 | やること | Ikkoma との差 |
|---|---|---|
| Duolingo / スタサプ | 用意されたコンテンツを順に消化 | Ikkoma は**コンテンツを持たない**。目標に対して今日やることを決め、AI が場で生成する |
| Anki / 単語アプリ | ユーザーが作ったカードを間隔反復 | Ikkoma は**カードを自分で作らせない**。学習セッションから自動で型を抽出してキューに入れる |
| Notion / Obsidian | 学習ログを自分で設計・記録 | Ikkoma は**記録を目的にしない**。記録はセッションの副産物として自動で残る |
| ChatGPT に毎回聞く | その場の質問には答える | Ikkoma は**現在地を覚えている**。昨日の弱点が今日のメニューに反映される |

## 設計原則

1. **必須ノルマは1日30分**。それ以上は任意。ハードルを上げない
2. **中断は失敗ではない**。paused は正常状態として一級市民に扱う
3. **曖昧な「勉強する」を出さない**。メニューは必ず「何を・どうやって・どこまで」まで具体化する
4. **記録はユーザーに書かせない**。セッションの結果から自動生成し、確認だけさせる
5. **AI の提案は上書き可能**。ユーザーが別トピックを希望したら常にそちらに従う
