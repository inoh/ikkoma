# 05. 画面設計

Figma で起こす画面の一覧と構成要素。Web アプリ（デスクトップ 1440 / モバイル 390）。
**モバイル優先**で設計する（学習は移動中・寝る前が多いため）。

## 画面一覧

| # | 画面 | 役割 | MVP |
|---|---|---|:---:|
| S1 | Today（ホーム） | 今日のメニューとストリーク。**最頻出画面** | ● |
| S2 | Session | メニュー項目を実行する対話画面 | ● |
| S3 | Session Result | 結果・抽出された弱点の承認 | ● |
| S4 | Topics | トピック一覧 | ● |
| S5 | Topic Detail | 目標・マイルストーン・学習ログ | ● |
| S6 | Weakness & Review | 弱点リストと復習キュー | ● |
| S7 | Dashboard | ストリーク・ヒートマップ・時間内訳 | ● |
| S8 | Onboarding | 目標入力 → マイルストーン提案 | ● |
| S9 | Settings | 通知・週次リズム | ● |
| S10 | Group / Share | グループストリーク・メンター共有 | Phase 2 |

## S1. Today（ホーム）

**この画面だけで「今日やること」が完結すること。** 迷わせない。

```
┌──────────────────────────────────┐
│  9月8日(火)          🔥 12日連続   │  ← ヘッダー: 日付 + ストリーク
├──────────────────────────────────┤
│  今日の30分                        │
│  ┌────────────────────────────┐  │
│  │ 5分  復習    TOEIC          │  │  ← メニュー項目カード
│  │ 昨日の弱点3型を再テスト       │  │     (時間 / 種別 / トピック / 具体指示)
│  │ 冠詞落ち・副詞語順・複合名詞  │  │
│  ├────────────────────────────┤  │
│  │ 20分 読解   AgentCore   ✓   │  │  ← 完了済みはチェック + 淡色
│  ├────────────────────────────┤  │
│  │ 5分  口頭試問 AgentCore     │  │
│  └────────────────────────────┘  │
│                                   │
│  [  今日の学習を始める  ]          │  ← Primary CTA
│  組み直す ・ 今日は5分だけ         │  ← 逃げ道を必ず用意する
└──────────────────────────────────┘
```

要素：
- **ストリークチップ**：炎アイコン + 日数。今日未実施なら淡色、実施済みで点灯
- **メニュー項目カード**：`時間バッジ` `種別ラベル` `トピック名` `タイトル` `具体指示`
  `status`（pending / done / skipped）
- **進捗バー**：30分中の消化分
- **CTA**：主「今日の学習を始める」／副「組み直す」「今日は5分だけ」
- **空状態**：トピック未作成時 → オンボーディングへの導線

## S2. Session

対話が主。ドリルカードと添削カードがチャット流に差し込まれる。

```
┌──────────────────────────────────┐
│ ← TOEIC 復習            ⏱ 3:12/5:00│  ← 残り時間タイマー
├──────────────────────────────────┤
│                                   │
│  🤖 では1問目です。               │
│  ┌────────────────────────────┐  │
│  │ Q1                          │  │  ← ドリルカード
│  │ The report was reviewed ___ │  │
│  │  A. careful   B. carefully  │  │
│  │  C. care      D. caring     │  │
│  └────────────────────────────┘  │
│                        [B] を選択 │
│  ┌────────────────────────────┐  │
│  │ ✓ 正解  動詞を修飾＝副詞     │  │  ← 即時フィードバックカード
│  │ 関連する弱点: 副詞の語順      │  │
│  └────────────────────────────┘  │
│                                   │
│  🤖 次は英作文です。今日の単語を   │
│     使って2文つくってください。    │
│                                   │
├──────────────────────────────────┤
│ [メッセージを入力]         [送信] │
└──────────────────────────────────┘
```

コンポーネント：
- `AIMessage` / `UserMessage`（チャットバブル）
- `DrillCard`（問題 + 選択肢 or 記述欄）
- `FeedbackCard`（正誤 + 解説 + 紐づく弱点型チップ）
- `CorrectionCard`（原文 / 添削後 / 差分ハイライト / 講評）
- `SessionTimer`（残り時間・一時停止）
- 中断バナー（「途中から再開」表示）

**弱点の承認が主目的。** ここを雑にすると弱点リストが汚れる。

│      TOEIC ・ 18分 ・ 8/10         │
├──────────────────────────────────┤

│  ┌────────────────────────────┐  │
│  │ 🔴 冠詞の付け忘れ   3回目     │  │  ← 再発は赤バッジ

## S4. Topics

```
カード一覧（active → paused → done の順）
┌────────────────────────────┐
│ TOEIC              active   │
│ 目標: 600点取得              │
│ ▓▓▓░░░░░░░ 15%              │
│ M2 基礎固め(品詞・前置詞)     │
│ 弱点 7型 ・ 最終学習 昨日     │
└────────────────────────────┘
[ + トピックを追加 ]
```
- active が2つある状態で追加しようとすると警告（3つ目は破綻しやすい）
- paused カードは淡色 + 「再開」ボタン + 中断理由の表示

## S5. Topic Detail

タブ構成：**概要 / マイルストーン / 弱点 / ログ**

- **概要**：目標・現在地メモ（編集可）・次の一手・定番メニュー
- **マイルストーン**：チェックリスト。完了で進捗更新。現在のものを強調
- **弱点**：このトピックの weakness_types（S6 のフィルタ済みビュー）
- **ログ**：日付 / 時間 / 内容の表。セッションから自動生成された行

ヘッダーに `中断する` / `再開する` / `完了にする` のアクション。

## S6. Weakness & Review

```
┌──────────────────────────────────┐
│ 弱点リスト        [今日の復習 3件] │
├──────────────────────────────────┤
│ 発生回数順                         │
│ ┌────────────────────────────┐  │
│ │ 冠詞の付け忘け        ●●●   │  │  ← 回数をドットで表現
│ │ 次回復習: 今日  ▓▓░░░ Lv2   │  │  ← 間隔反復レベル
│ ├────────────────────────────┤  │
│ │ be動詞と一般動詞の併用  ●●  │  │
│ │ 次回復習: 9/11  ▓▓▓░░ Lv3   │  │
│ └────────────────────────────┘  │
│  卒業した型 (2)  ▸               │  ← 折りたたみ
└──────────────────────────────────┘
```
- `WeaknessCard`：ラベル / 発生回数 / 例（誤・正）/ 次回復習日 / 間隔レベル / 状態
- ソート：発生回数・次回復習日・最終再発日
- 「今日の復習」からその場で復習セッションに入れる

## S7. Dashboard

- **ストリークヒーロー**：現在 / 最長 / 累計日数
- **ヒートマップ**：52週 × 7日。濃度＝学習時間
- **トピック別時間**：積み上げ棒（週次）
- **弱点の推移**：active 型数の折れ線（減っていれば効いている）
- **週次サマリカード**：今週やったこと・新規弱点・卒業した型（AI 生成テキスト）

## S8. Onboarding

ステップ形式（進捗インジケータ付き）。F1 の7ステップに対応。
- 目標入力は**大きな1つの入力欄**。プレースホルダで例を見せる
- マイルストーン提案は**編集可能なカードリスト**として出す（読むだけにしない）
- レベルチェックは S2 と同じセッション UI を使い回す

## S9. Settings

- 通知（昼／夜の時刻、チャネル、ON/OFF）
- 週次リズム（曜日 × トピックのマトリクス編集、warmup トグル）
- 1日の目標時間（既定30分）
- アカウント

## S10. Group / Share（Phase 2）

- グループのストリーク一覧（メンバー / 連続日数 / 今日の実施状況）
- メンター共有の権限設定
- 公開テンプレートの一覧・複製

## Figma に起こす順序

1. **デザイントークン**（08 参照）を Variables として定義
2. コンポーネント：Button / Card / Chip / Tag / ProgressBar / StreakBadge /
   MenuItemCard / DrillCard / FeedbackCard / WeaknessCard / ChatBubble / TabBar
3. 画面：S1 → S2 → S3（コアループ）→ S6 → S7 → S4 → S5 → S8 → S9
4. フロー：S1 → S2 → S3 → S1 の矢印を FigJam / プロトタイプで接続
