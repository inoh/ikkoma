## タイポグラフィ

Font: **Inter**（英数） / **Noto Sans JP**（日本語）

| トークン | サイズ / 行間 / ウェイト | 用途 |
|---|---|---|
| display | 32 / 40 / Bold | ストリーク数値 |
| h1 | 24 / 32 / Semi Bold | 画面タイトル |
| h2 | 20 / 28 / Semi Bold | セクション |
| h3 | 16 / 24 / Semi Bold | カードタイトル |
| body | 15 / 24 / Regular | 本文 |
| body-sm | 13 / 20 / Regular | 補助テキスト |
| label | 12 / 16 / Medium | バッジ・ラベル |
| mono | 13 / 20 / Regular | 例文の誤／正表示 |

## スペーシング

4px 基準： `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`

- カード内パディング：16（モバイル）／20（デスクトップ）
- セクション間：24
- 画面左右パディング：16（モバイル）／32（デスクトップ）

| radius/lg | 14 | カード |

| | 幅 |
|---|---|

## トーン

- **落ち着いた集中感**。ゲーミフィケーションの色圧は最小限
- 色で騒ぐのはストリークと正誤フィードバックの瞬間だけ
- 空白を多く取る。1画面に情報を詰めない
